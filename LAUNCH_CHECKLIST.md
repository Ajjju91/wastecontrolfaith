## If Issues Occur

### Issue: Pages not showing
**Solution:**
- [ ] Wait 3-5 minutes (GitHub Pages needs time to build)
- [ ] Clear browser cache (Ctrl+Shift+Delete)
- [ ] Try private/incognito window
- [ ] Check GitHub repository settings

### Issue: Styling not loading (site looks bare)
**Solution:**
- [ ] Verify styles.css uploaded correctly
- [ ] Check file name spelling (case-sensitive)
- [ ] Ensure styles.css in same folder as HTML
- [ ] Check browser console for errors (F12)
- [ ] Try hard refresh (Ctrl+F5)

### Issue: Links not working
**Solution:**
- [ ] Verify all HTML files uploaded
- [ ] Check file names match in links
- [ ] Ensure .html extensions included in links
- [ ] Verify links use correct paths
- [ ] Check for typos in file names

### Issue: Mobile layout broken
**Solution:**
- [ ] Verify viewport meta tag in HTML
- [ ] Check CSS responsive breakpoints
- [ ] Test in Chrome DevTools (F12 → Toggle device toolbar)
- [ ] Clear browser cache
- [ ] Check for CSS width issues
