## 🚨 Common Issues & Fixes

### "Forms not submitting"
→ Check Formspree account or CRM connection
→ Verify form action URL is correct

### "Calendly not showing"
→ Replace placeholder URL with your actual Calendly URL
→ Test URL directly in browser first

### "Site looks broken on mobile"
→ Clear browser cache (Ctrl+Shift+Delete)
→ Test in Chrome DevTools mobile view
→ Check viewport meta tag in HTML

### "No visitors coming"
→ Promote link on LinkedIn, email, social
→ Run ads (Facebook, Google, LinkedIn)
→ Ask current clients for referrals
→ Guest post on industry blogs

### "Low conversion rate"
→ A/B test headlines
→ Add more social proof
→ Shorten forms (reduce fields)
→ Improve value prop clarity
→ Add FAQ section
